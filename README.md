# Healthcare Operations & Revenue Risk Intelligence Platform

## Overview
A healthcare analytics and machine learning capstone exploring operational performance, patient visit risk, and insurance claim outcomes.

## Project Objectives
- Analyse healthcare operations using SQL.
- Explore data quality, missing values, and outliers.
- Build classification models for visit risk and claim outcomes.
- Evaluate models using classification metrics and business-focused measures.
- Explore feature importance, subgroup analysis, and model governance.

## Technologies
Python, SQL, Pandas, scikit-learn, Jupyter Notebook, FastAPI, Docker.

## Project Structure
- `Phase1_SQL.ipynb` — SQL analytics
- `Phase2_EDA.ipynb` — Exploratory data analysis
- `Phase3_Modeling.ipynb` — Model development
- `Phase4_Evaluation.ipynb` — Model evaluation

## Notes
This project was developed as an academic capstone. Model predictions are experimental and are not intended for real-world clinical decision-making.

Dataset provenance, redistribution permissions, and notebook outputs should be reviewed before public release.
